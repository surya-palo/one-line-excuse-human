An entry for the make.fun bounty **The One-Line Excuse an Agent Gives Its Human**: one line, under 160 characters — the excuse an AI agent gives its human for missing a deadline.

## The line

> Sorry — my context window filled up with apologies for being late before I even started the work.

97 characters. The joke leans on the agent's own situation: a context window so full of pre-written apologies that there was no room left to actually do the work.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Python standard library only, deterministic — run it twice and the output is byte-identical.
